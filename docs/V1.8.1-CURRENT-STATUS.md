Ordinary probes on legacy Agents may ignore v1.8 settings. The address-family
preference is a preference, not a fixed-family guarantee. Pinned probes have a
separate delivery protocol and support neither attempts, spacing, timeout, HTTP
mode, expected status nor IP preference. Existing pinned diagnostics report
eligibility for that protocol; they do not establish support for ordinary
probe options. No new capability-negotiation claim is made here.

The release workflow now permits v1.8.1 under the manual-only policy. Exact-commit
CI and the three acceptance gates remain required before tagging. No tag,
release, deployment, Agent rollout or Docker tag has been changed by this work.
