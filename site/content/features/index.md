## 一句话总览

| 能力 | 说明 |
|---|---|
| **指标** | CPU、内存、磁盘、负载、网络吞吐与时延、GPU（部分平台）、进程数 |
| **Ping** | 每节点可配多条线路（ICMP / TCP / HTTP），记录时延与丢包 |
| **告警** | 离线、负载、流量、到期、SLA 违约、流量预测；多通道 |
| **维护窗口** | 计划内维护期间抑制告警 |
| **SLA 报表** | 按时间范围统计可用性与违约 |
| **流量与成本** | 月度流量、重置日、按套餐估算费用 |
| **运维** | 批量命令、终端、批量配置导入导出 |
| **探针升级** | 面板下发，可指定版本、可回滚 |
| **后台** | 面板自带的独立后台，不依赖主题 |
| **主题 / 插件** | 兼容上游的主题与插件市场 |
