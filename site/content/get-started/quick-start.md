# 首次配置

面板起来之后，这一页把一台机器接进来。

## 1. 完成安装向导

首次访问面板地址会进入安装向导，设置管理员账号与密码。

!!! tip "建议同时开启 2FA"
    面板暴露在公网是常态。安装完成后在 **账户** 里开启两步验证，并保存好恢复码。

## 2. 添加节点

在 **服务器列表** 里点「添加节点」。面板会生成一个**该节点专属的 token**，并给出可直接执行的安装命令。

安装脚本会：

1. 下载对应平台的探针二进制，核对 `SHA256SUMS.txt`
2. 写入 token 文件（权限 `0600`，不进命令行，避免出现在 `ps` 里）
3. 注册并启动系统服务

```bash
# 面板给出的命令形如（token 由面板生成，不要复用）
curl -fsSL https://your-panel/install.sh | sudo bash -s -- \
  -e https://your-panel -t <node-token>
```

## 3. 确认它连上了 { #confirm-online }

节点列表里该条目应从"离线"变为在线，并在十几秒内出现 CPU、内存、磁盘数据。

没连上时按这两条通道分别判断 —— 它们**是独立的**：

| 现象 | 哪条通道有问题 |
|---|---|
| 完全没有数据 | **上报**（HTTP）不通：探针连不到面板，或 token 不对 |
| 有数据但远程执行/终端/升级点不动 | **下发**（WebSocket）不通：通常是前端代理没透传 `Upgrade` 头，或读超时太短 |

排查看探针日志：

```bash
journalctl -u komari-agent -f          # systemd 节点
rc-service nekomari-agent status       # Alpine / OpenRC 节点
```

报告通信的**类型**而不是具体内容：面板会给探针每组任务分配编号，日志里能对上。

## 4. 按需设置分组与账单

节点列表支持分组、私有备注、账单周期与到期提醒。这些是面板侧的元数据，不影响探针。

填了账单信息之后，**资产概览**与**流量与成本预测**才有数据。
